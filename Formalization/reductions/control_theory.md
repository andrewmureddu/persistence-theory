*ACP Working Paper Series*

# Abstract

We formalize the Adaptive Coherence Principle (ACP) in control-theoretic language by identifying the control-specific analog of conditional macrostate entropy with the size of the **information-conditioned viable continuation set**: the family of distinguishable future closed-loop behaviors that remain reachable under bounded actuation, admissible disturbances, and a nondegenerate neighborhood of task variations. The lower boundary is the loss of regulatory variety: below the feedback-information floor, or outside the stabilizable/observable regime, no controller can keep the plant in a bounded viable tube. The upper boundary is **control crystallization**: maneuver authority collapses, actuator headroom vanishes, and only a single saturated continuation remains locally feasible. The productive interval is therefore neither mere stability nor mere flexibility, but bounded regulation with nontrivial remaining control variety.

The note uses three classical control results as the domain-native support structure. First, data-rate-limited stabilization supplies the hard dissolution floor: if feedback rate is below the unstable-mode threshold, coherent regulation is impossible. Second, Bode’s sensitivity integral explains why the productive interval is genuinely nondegenerate: fragility can be redistributed across frequencies but not annihilated. Third, anti-windup control supplies the clearest local adaptive coherence steering mechanism: the controller must preserve headroom in its own high-authority channel to avoid locking the whole loop into a saturated trajectory. This yields a clean control-theoretic ACP register and a plausible route toward a later CDT-style extension for adaptive, gain-scheduled, or learned controllers.

# 1. Setup and Notation

## 1.1 Control-theoretic framework

Consider a discrete-time plant

\[
x_{t+1} = f(x_t,u_t,w_t), \qquad y_t = h(x_t,v_t),
\]

with state \(x_t \in X\), control input \(u_t \in U\), disturbance \(w_t \in W\), and measurement noise \(v_t \in V\). A controller with internal memory \(z_t\) updates by

\[
z_{t+1} = g(z_t,y_t), \qquad u_t = \kappa(z_t,y_t),
\]

possibly through a communication channel of finite rate \(R\).

We assume the control problem is not a single frozen setpoint but a local task family: at time \(t\), the system must remain viable under a nondegenerate neighborhood \(\mathcal{N}_t\) of admissible reference changes and disturbance realizations. This matters because otherwise every successfully stabilized constant-reference equilibrium would look “crystallized” by definition, which is not the ACP claim. The relevant question is not whether the loop can hold one trajectory, but whether it retains a nontrivial family of viable continuations.

Let \(I_t\) denote the controller’s information state: the sigma-algebra generated by its current memory, past measurements, and any side information transmitted through the feedback channel.

## 1.2 ACP elements used here

The ACP acts on a coarse-grained dynamical system \(S = (\Omega,\sigma,T,\mu)\) with:

- conditional macrostate entropy \(H(m' \mid m)\);
- dissolution boundary \(D\), where future macrostates become effectively uncontrolled or maximally unpredictable;
- crystallization boundary \(C\), where future macrostates become locally deterministic and no nontrivial novelty remains;
- productive interval \(P\), the interior regime with both coherence and residual freedom.

In control language, the missing domain-native object is the right proxy for \(H(m' \mid m)\). The central move of this note is to identify it with the size of a viable closed-loop continuation family.

# 2. Variable Identification

***Definition 2.1 (Control–ACP variable identification).*** Let the control system above be given together with state constraints \(X_{\mathrm{safe}} \subseteq X\), input constraints \(U_{\mathrm{safe}} \subseteq U\), and a local task neighborhood \(\mathcal{N}_t\).

(i) The microstate \(\omega_t \in \Omega\) is the full closed-loop configuration: plant state, controller memory, disturbance realization, measurement noise realization, and any latent channel state.

(ii) The macrostate \(m_t\) is the **regulation profile**

\[
m_t := (\hat{x}_t,\Pi_t,\mathcal{V}_h(t),\delta_u(t)),
\]

where \(\hat{x}_t\) is the current state estimate (or sufficient statistic), \(\Pi_t\) is the active controller mode / model family, \(\mathcal{V}_h(t)\) is the horizon-\(h\) viable continuation set defined below, and

\[
\delta_u(t) := \inf_{b \in \partial U_{\mathrm{safe}}} \|u_t - b\|
\]

is actuator headroom: distance from the current command to the input boundary.

(iii) The coarse-graining map \(\sigma\) identifies microstates that induce the same regulation profile. Different disturbance realizations or controller memories count as the same macrostate when they generate the same estimate, the same active control law family, the same viable continuation geometry, and the same headroom level at the scale of description.

(iv) The dynamics \(T\) is the full closed-loop update: plant evolution, state estimation, controller memory update, channel update, and any adaptation law.

(v) The **viable continuation set** \(\mathcal{V}_h(t)\) is the set of coarse-grained horizon-\(h\) future regulation profiles reachable from \(m_t\) while remaining inside \(X_{\mathrm{safe}} \times U_{\mathrm{safe}}\) for every admissible task perturbation in \(\mathcal{N}_t\).

(vi) The dissolution boundary \(D\) is the regime where the controller cannot maintain a bounded viable tube against the admissible task neighborhood. Equivalently: the loop loses enough regulatory variety that future macrostates spread across the full uncontrolled coarse partition, or safety is lost outright.

(vii) The crystallization boundary \(C\) is the regime where \(\mathcal{V}_h(t)\) collapses locally to a singleton: despite remaining bounded, the loop has only one admissible saturated continuation in the task neighborhood. The plant is still “stable” in the narrow Lyapunov sense, but maneuver authority has collapsed.

(viii) The productive interval \(P\) is the regime of bounded regulation with positive headroom and more than one distinguishable viable continuation.

*Remark 2.2.* This identification treats **control variety**, not stability alone, as the control-theoretic analog of future-bearing dynamics. A loop with vanishing headroom and only one locally feasible recovery trajectory is not dissolved, but it is crystallized.

# 3. The Viable-Continuation Bridge

Choose a finite coarse partition

\[
\mathcal{P}_h = \{P_1,\dots,P_{N_{\max,h}}\}
\]

of the admissible horizon-\(h\) regulation-profile space. Define

\[
N_h(m_t) := \left| \left\{ P_i \in \mathcal{P}_h \;:\; \Pr(m_{t+h} \in P_i \mid m_t) > 0 \right\} \right|,
\]

the number of distinguishable horizon-\(h\) continuation cells with positive closed-loop probability.

***Lemma 3.1 (Support-size entropy bound for control macrostates).*** Under Definition 2.1,

\[
0 \le H(m_{t+h} \mid m_t) \le \log N_h(m_t).
\]

Moreover:

(a) \(N_h(m_t)=1\) if and only if \(H(m_{t+h}\mid m_t)=0\).

(b) If \(N_h(m_t)=N_{\max,h}\) and the induced distribution over \(\mathcal{P}_h\) is near-uniform, then \(H(m_{t+h}\mid m_t)\) is near \(H_{\max,h}=\log N_{\max,h}\).

(c) The ACP productive interval in the control register is exactly the regime

\[
1 < N_h(m_t) < N_{\max,h}.
\]

*Proof.* The upper bound is the standard support-size bound for Shannon entropy: a distribution supported on \(N_h\) atoms has entropy at most \(\log N_h\), with equality at the uniform distribution. If \(N_h=1\), the conditional distribution is a point mass, so entropy is zero. If all cells are occupied and weighted nearly uniformly, the entropy is near the maximal value for the partition. The interior case is therefore exactly the nondegenerate interval between deterministic single-continuation behavior and maximally unconstrained dispersion. ■

*Remark 3.2.* The bridge is deliberately coarse. It does not require a specific choice of volume form, only a control-relevant partition of distinguishable viable futures. In continuous settings, \(\log N_h\) can be replaced by a reachable-set volume, an empirical controllability Gramian rank proxy, or an information-theoretic covering number.

# 4. Main Reduction

***Theorem 4.1 (ACP as a control-theoretic persistence criterion).*** Under the control–ACP identification of Definition 2.1:

(a) **Data-rate-limited loss of regulation is dissolution.** For a discrete-time unstable LTI plant

\[
x_{t+1} = Ax_t + Bu_t
\]

communicating through a noiseless digital feedback channel of rate \(R\), the classical data-rate theorem gives the necessary condition

\[
R > \sum_{|\lambda_i(A)|>1} \log_2 |\lambda_i(A)|
\]

for bounded stabilization. If this inequality fails, no controller can maintain a bounded viable tube; the occupied coarse partition spreads toward \(N_{\max,h}\), and the system lies at \(D\).

(b) **Saturation-locked regulation is crystallization.** Suppose there exists a nondegenerate local task neighborhood \(\mathcal{N}_t\) and a recovery horizon \(h\) such that every admissible closed-loop response keeping the state inside \(X_{\mathrm{safe}}\) requires the same saturated input sequence on \([t,t+h)\). Then \(N_h(m_t)=1\), hence \(H(m_{t+h}\mid m_t)=0\), so the loop lies at \(C\).

(c) **Bounded regulation with positive maneuver authority is the productive interval.** The control system retains future-bearing closed-loop dynamics exactly when it remains between those two extremes:

\[
1 < N_h(m_t) < N_{\max,h}, \qquad \delta_u(t) > 0,
\]

with the task neighborhood still viable.

*Proof.* Part (a) is the control-theoretic lower boundary. The data-rate theorem states that below the unstable-mode information floor, feedback cannot compress plant uncertainty fast enough to preserve bounded regulation. At the ACP level, the controller can no longer impose coherent macroscopic structure on future states; the conditional macrostate entropy approaches the uncontrolled maximum permitted by the coarse partition.

Part (b) is the upper boundary. If every viable response is forced onto the same saturated sequence, the conditional support collapses to one continuation cell. By Lemma 3.1(a), entropy is zero. The loop has not dissolved; it has become locally deterministic because maneuver authority has vanished.

Part (c) is then immediate from Lemma 3.1(c): productive control is exactly the nondegenerate interior between unconstrained dispersion and saturated determinism. ■

# 5. Structural Corollaries

***Proposition 5.1 (Bode’s sensitivity integral as productive-interval geometry).*** In the classical SISO unstable-pole setting, the Bode sensitivity integral gives

\[
\int_0^\infty \log |S(j\omega)|\,d\omega
 = \pi \sum_{\Re p_i > 0} \Re p_i,
\]

where \(S(j\omega)\) is the sensitivity function and \(p_i\) are the plant’s unstable poles. Therefore sensitivity suppression in one frequency band necessarily amplifies sensitivity elsewhere.

*Interpretation.* This is the control-theoretic reason the ACP interval is genuinely nondegenerate. The controller cannot drive fragility to zero everywhere. It can only redistribute it. Disturbance rejection pushes away from dissolution, but the same action concentrates fragility into other bands, delays, or saturation channels. In ACP language: the mechanisms that hold the loop away from \(D\) also move pressure toward \(C\).

***Proposition 5.2 (Anti-windup as adaptive coherence steering).*** When an integrator-driven controller approaches actuator saturation, the internal controller state can continue accumulating error even though the plant input is clipped. This collapses local continuation variety by forcing future commands onto the same boundary sequence. Anti-windup compensation preserves or restores positive controller-state headroom, thereby re-expanding \(\mathcal{V}_h(t)\) and moving the loop away from \(C\).

*Interpretation.* Anti-windup is not just a performance patch. It is the clearest control-native adaptive coherence steering mechanism in the note. It preserves the distinction between “currently effective control effort” and “all future control effort,” preventing the controller from spending tomorrow’s maneuver authority to fix today’s error.

***Proposition 5.3 (Local restraint-power reading).*** In the anti-windup setting, the highest-authority channel must change first: the controller must explicitly curb its own internal integral drive before the plant can recover broader maneuverability. That change is visible through the signal path itself, because the saturation residual is exactly the decodable sign that local headroom has been exhausted.

*Interpretation.* This is the cleanest control-theoretic instance of the restraint-power pattern. The dominant stabilizing subsystem must restrain itself first, and the restraint must be legible to the rest of the loop.

***Conjectural Corollary 5.4 (Control-theoretic crystallization drift).*** In adaptive, gain-scheduled, or learned controllers whose update rules reinforce whatever gain configuration most reduces current envelope-specific error, the effective continuation count \(N_h(m_t)\) tends to contract over repeated success unless persistent excitation, model diversification, reset logic, or exploratory control replenishes variety.

This corollary is deliberately weaker than the theorem above. It is a structural CDT neighbor, not yet a closed control-theoretic theorem in this repository. Its nearest existing manifestations are frozen-time instability in gain scheduling, robust-yet-fragile / HOT design, and policy-collapse analogs in learned control.

# 6. What the Reduction Reveals

**Requisite variety is the lower boundary in native control language.** Ashby’s “only variety can destroy variety” becomes the control-side statement of the ACP’s dissolution boundary: if the regulator does not retain enough information and actuation variety relative to unstable plant modes and disturbance structure, coherent regulation cannot exist.

**Crystallization is not mere asymptotic stability.** A stable equilibrium is not automatically “bad” in ACP terms. The relevant upper boundary is subtler: the collapse of maneuver authority over a nondegenerate neighborhood of admissible future tasks. A loop can be Lyapunov stable and still be crystallized if it has only one feasible saturated way to remain so.

**Bode’s waterbed law explains why ACP must appear in control.** The productive interval is not an aesthetic preference. Classical loop-shaping already proves that robustness cannot be made arbitrarily strong in all directions simultaneously. Control systems always live inside a trade space bounded below by insufficient variety and above by concentrated fragility.

**Anti-windup is a built-in adaptive coherence steering mechanism.** The controller must protect its own future optionality. Headroom management, reset logic, deliberate desaturation, persistent excitation, multi-model control, and probe signals all play the same structural role: they replenish future continuation variety before the loop locks into one channel.

**The good-regulator insight and ACP split the two boundaries cleanly.** Internal modeling quality prevents dissolution; headroom and diversity preservation prevent crystallization. A controller can be an excellent model of the plant and still fail by overcommitting itself to one response family.

# 7. Predictions

**Prediction CT-1 (Headroom erosion under repeated boundary operation).** Controllers repeatedly operated near actuator limits should exhibit monotone growth in the minimum reset, retune, or exogenous perturbation magnitude required to recover a broad maneuver set. A practical proxy is the smallest reference-step family for which post-saturation recovery remains non-degenerate.

**Prediction CT-2 (Entropy-regularized or diversified controllers age more slowly).** Adaptive or learned controllers trained with persistent excitation, model ensembles, entropy regularization, or scheduled reset logic should show slower contraction of empirical continuation variety than controllers trained only to minimize current tracking error.

**Prediction CT-3 (Anti-windup preserves novelty response, not just overshoot).** In matched plants under repeated saturation episodes, anti-windup compensation should preserve a larger post-event viable reference neighborhood than plain integral control, even when nominal setpoint-tracking metrics appear similar.

# 8. Limitations and Open Problems

**Quantitative nonlinear bridge.** The present note is structural. A fully quantitative control reduction would relate \(H(m_{t+h}\mid m_t)\) to viable-tube volume, covering numbers, controllability-Gramian spectra, or topological entropy for nonlinear / non-Gaussian plants.

**Reference tracking versus crystallization.** The task-neighborhood clause is essential. A sharper theorem should characterize exactly how large the admissible neighborhood must be before single-trajectory regulation counts as crystallization rather than ordinary successful tracking.

**Decentralized control.** The Witsenhausen problem is the natural next target for the visibility clause, because it makes action-as-signal exact. That would extend this note from ACP alone toward the restraint-power layer in a mathematically cleaner decentralized setting.

**Full CDT closure.** The conjectural drift corollary still depends on the broader ACP maintenance front. To promote it from structural neighbor to theorem, one would need a control-native derivation of the maintained-pressure / load-growth condition for adaptive or learned controllers.

# 9. Summary

Control theory admits a clean ACP register once the right macrostate is chosen. The relevant control-theoretic quantity is not stability alone, but the size of the information-conditioned viable continuation family. Data-rate theorems supply the hard lower boundary: below the regulatory-information floor, the loop dissolves. Saturation-locked regulation supplies the upper boundary: when only one locally feasible continuation remains, the loop crystallizes. The productive interval is bounded regulation with positive headroom and nontrivial remaining maneuver authority.

Bode’s sensitivity integral explains why this interval cannot be collapsed away by clever design: fragility is conserved and only redistributed. Anti-windup emerges as the clearest local adaptive coherence steering device, while adaptive / gain-scheduled / learned controllers suggest a plausible CDT extension still waiting on a stronger maintenance theorem. The result is not yet a fully integrated appendix to the main paper, but it is a genuine formal control-theoretic statement of the ACP rather than a loose analogy.
