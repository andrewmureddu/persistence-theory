# Persistence Theory

[![DOI](https://zenodo.org/badge/1215868056.svg)](https://zenodo.org/badge/latestdoi/1215868056)

This repository contains the Adaptive Coherence Principle formalization workspace and its public-facing Astro website.

## Repository Layout

- `Formalization/` - source-of-truth research workspace for the Adaptive Coherence Principle (ACP), the Crystallization Drift Theorem (CDT), proofs, reductions, empirical scaffolds, simulations, and session logs.
- `website/` - Astro presentation site for the project.
- `agent_handler/` - experimental local agent runtime and service code.

## Citation

This repository is prepared for archival through Zenodo's GitHub integration. After the first GitHub release is archived, the DOI badge above will resolve to the latest Zenodo DOI.
